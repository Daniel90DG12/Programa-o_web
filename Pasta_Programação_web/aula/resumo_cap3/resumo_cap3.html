Resumo do Capitulo 3

Introdução ao CSS

O CSS (Cascading Style Sheets) é uma linguagem de estilo que controla a aparência visual dos elementos HTML em uma página web. Com o CSS, você pode definir fontes, cores, dimensões, bordas, listas, formulários, tabelas e o layout geral da página. O objetivo principal é transformar o HTML visualmente "sem graça" em páginas mais atraentes e profissionais.

3.1 Introdução aos Conceitos Fundamentais

3.1.1 O Princípio do CSS

Uma regra CSS consiste em duas partes principais:

  • Seletor:Define quais elementos HTML serão afetados
  • Declaração(entre chaves {}): Define como esses elementos serão exibidos
A declaração, por sua vez, é composta por:
  • Propriedade:O aspecto visual a ser modificado (ex: font-family, color)
  • Valor:A especificação exata da propriedade (ex: Arial, darkblue)

Exemplo de codigo CSS
h1 { font-family: Arial; color: darkblue; }

3.1.2 Inclusão do CSS no HTML

Existem três formas principais de incluir CSS:

  1. CSS Externo (External Stylesheets) — método mais recomendado:
    • O CSS é salvo em um arquivo separado (.css)
    • Incluído via elemento <link> no <head> do HTML
    • Vantagem:permite reutilização em múltiplos documentos HTML e manutenção centralizada
  2. CSS Interno (Internal Stylesheets):
    • CSS definido dentro do elemento <style> no <head> do HTML
    • Desvantagem: não é reutilizável entre páginas; dificulta a sincronização de alterações
    • CSS definido diretamente no atributo style de um elemento HTML
    • Desvantagem:perde totalmente a reutilização; deve ser usado apenas em casos excepcionais
Nota adicional: Também é possível importar arquivos CSS dentro de outros arquivos CSS usando @import url(...).

3.1.3 Seletores CSS

O capítulo apresenta uma tabela completa de tipos de seletores:

Tipo de Seletor Descrição Exemplo
Seletor de Tipo Seleciona todos os elementos de um tipo input { }, h1, h2 { }
Seletor de Classe Seleciona elementos com uma classe específica .valid { }, a.valid { }
Seletor de ID Seleciona um elemento com ID específico (deve ser único) #start { }, p#start { }
Seletor Universal Seleciona todos os elementos * { }
Seletor de Atributo Seleciona elementos com base em atributos [type="text"] { }
Seletor de Filho Direto Seleciona filhos diretos de um elemento body > ul { }
Seletor de Descendente Seleciona todos os descendentes de um elemento body ul { }

Combinação de seletores: É possível criar seletores complexos combinando múltiplos tipos, como form#order-details > input.important[type="text"].

3.1.4 Cascata e Especificidade

O termo "Cascading" (em cascata) refere-se à forma como as regras CSS são aplicadas:

  • Regra 1: Quando dois seletores idênticos se aplicam ao mesmo elemento, o último definido prevalece
  • Regra 2: Quando os seletores são diferentes, o seletor com maior especificidade prevalece
Cálculo da Especificidade (sistema de contadores A, B, C):
  • A: +1 para cada seletor de ID
  • B: +1 para cada seletor de classe, atributo ou pseudo-classe
  • C: +1 para cada seletor de tipo ou pseudo-elemento
Exemplos de especificidade (do menos para o mais específico):
  • *{} --> 000
  • h1 {} --> 001
  • ol li {} --> 002
  • div:first-child {} --> 011
  • a.test[href] {} --> 021
  • #anchor {} --> 100
  • #chapter p {} --> 101
Regras inline(atributo style) têm a maior especificidade possível.
Pseudo-classes: Selecionam elementos em condições especiais:
  • :link,:visited ,:hover ,:active ,:focus(para links)
  • :first-child, :nth-child()
Pseudo-elementos: Selecionam partes específicas de elementos ou criam novos elementos:
  • ::before,::after ,::first-letter ,::first-line ,::selection

3.1.5 Herança

Algumas propriedades CSS são herdadas pelos elementos filhos a partir dos elementos pai, como color e font-family. Outras propriedades, como as de borda (border), não são herdadas — caso contrário, uma borda definida em um elemento se aplicaria a todos os seus descendentes.

3.2 Aplicação de Cores e Formatação de Texto

3.2.1 Definição de Cores

A propriedade color define a cor do texto. A propriedade background-colorbackground-color define a cor de fundo. Ambas aceitam os mesmos formatos de valor:

  • Nomes de cores:darkblue, yellow, hotpink (mais de 140 nomes predefinidos)
  • Valores hexadecimais: #FFFF00 ou forma curta #FF0
  • Valores RGB:rgb(255, 255, 0)
  • Valores RGBA (com transparência/alpha): rgba(255, 255, 0, 0.5)
  • Valores HSL(matiz, saturação, luminosidade):hsl(60, 100%, 50%)
  • Valores HSLA (HSL com alpha): hsla(60, 100%, 50%, 0.5)

3.2.2 Design de Textos

O capítulo apresenta diversas propriedades para formatação de texto:
Fontes (font-family):

  • Especifica a fonte do texto
  • É recomendável definir fontes fallback separadas por vírgula
  • Se o nome da fonte contiver espaços, deve estar entre aspas
  • Fontes genéricas recomendadas como último fallback:
    • serif (fontes com serifas, boas para impressão)
    • sans-serif (fontes sem serifas, melhores para telas)
    • monospace (fontes de largura fixa, ideais para código)
    • cursive e fantasy (uso discreto, não para textos longos)
Tamanho da Fonte (font-size):
  • Pixels (px): tamanho absoluto em pixels de tela
  • Porcentagem (%) relativo ao tamanho padrão do navegador (geralmente 16px)
  • em: relativo à largura da letra "m" da fonte atual
Estilo da fonte:
  • font-style: italic, oblique, normal
  • font-weight: normal (400), bold (700), lighter, bolder, ou valores numéricos de 100 a 900
Outras opções de formatação de texto:
  • text-transform: uppercase, lowercase, capitalize
  • text-decoration: underline, line-through, overline, blink (evitar)
  • line-height: espaçamento entre linhas
  • letter-spacing: espaçamento entre letras
  • word-spacing: espaçamento entre palavras
  • text-aligntext-align: alinhamento horizontal (left, right, center, justify)
  • vertical-align: alinhamento vertical (top, bottom, middle)
  • text-indent: recuo da primeira linha
  • text-shadow: sombra no texto
Formatação de Links
Usando pseudo-classe para diferentes estados de links:
Exemplo de codigo CSS
a:link { color: blue; } /* Não visitados */
a:visited { color: green; } /* Já visitados */
a:hover { color: black; background-color: orange; } /* Mouse sobre */
a:active { color: red; } /* Clicando */
a:focus { color: orange; } /* Com foco */
O capítulo inclui um exemplo completo de página de blog formatada com CSS, demonstrando a aplicação prática de todas essas propriedades.

Dica prática: As ferramentas de desenvolvedor dos navegadores (Chrome DevTools) permitem inspecionar quais regras CSS se aplicam a cada elemento, visualizando tanto a aba "Styles" (regras aplicáveis) quanto "Computed" (propriedades finais calculadas).

3.3 Listas e Tabelas

3.3.1 Design de Listas

Listas não ordenadas(<< ul >) — propriedade list-style-type:

  • none: sem marcador
  • disc: círculo preto (padrão)
  • circle: círculo vazio
  • square: quadrado preto
Listas ordenadas (<< ol >) — propriedade list-style-type:
  • decimal: 1, 2, 3...
  • decimal-leading-zero: 1, 2, 3...
  • lower-alpha: a, b, c...
  • upper-alpha: A, B, C...
  • lower-roman: i, ii, iii...
  • upper-roman: I, II, III...
Imagens como marcadores:
  • list-style-image: url("images/star.png")
Posição dos marcadores(list-style-position)
  • outside: marcadores à esquerda do bloco de texto (padrão)
  • inside: marcadores indentados dentro do bloco de texto

3.3.2 Design de Tabelas

Tabelas por padrão são visualmente "simples". Com CSS, podemos criar tabelas muito mais atraentes:

Propriedades principais para tabelas:

  • border: propriedade shorthand para largura, estilo e cor da borda
  • border-collapse: collapse: faz com que as bordas das células adjacentes se fundam em uma única borda
  • padding: espaço entre o conteúdo da célula e sua borda
Pseudo-classes úteis para tabelas:
  • :first-child: seleciona o primeiro filho (ex: primeira coluna)
  • :nth-child(n): seleciona filhos em posições específicas
    • :nth-child(odd) — linhas ímpares
    • :nth-child(even) — linhas pares
Exemplo prático: Uma tabela de livros recomendados sobre CSS, com cabeçalho escuro, linhas zebradas (alternadas), primeira coluna em negrito, segunda em itálico, e terceira alinhada à direita.

3.4 Sistemas de Layout

3.4.1 Princípios Básicos de Posicionamento

Elementos de nível de bloco vs. inline:

  • Block-level: sempre começam em uma nova linha (ex: < div >,< p > ,< h1 > )
  • Inline-level:fluem no texto (ex: < span >,< a > ,< strong >)
  • A propriedade display pode alterar esse comportamento: block, inline
Tipos de posicionamento (position):
  • static: posicionamento padrão no fluxo normal
  • relative: posicionado relativamente à sua posição original
  • absolute: removido do fluxo normal, posicionado relativamente ao elemento pai
  • fixed: posicionado relativamente à janela do navegador (viewport)
  • sticky: comporta-se como relative até um ponto de rolagem, depois como fixed
  • inherit: herda o posicionamento do elemento pai

3.4.2 Layout Float

O layout float usa a propriedade float para alinhar elementos à esquerda ou direita, interrompendo o fluxo normal do texto.

Exemplo prático: Formulário estilizado com float, onde rótulos (<< label >) flutuam à esquerda e campos de entrada (<< input >) à direita. A propriedade overflow: hidden no container (<< form >) garante que ele se expanda para conter todos os elementos flutuantes.

Propriedades importantes no exemplo:

  • width e max-width: definem largura preferida e máxima
  • box-sizing: border-box inclui padding e borda no cálculo da largura total

3.4.3 Layout Flexbox

Introduzido no CSS3, o Flexbox é muito mais flexível que o float. O conceito principal é permitir que um container ajuste dinamicamente a largura e altura de seus itens filhos para preencher o espaço disponível.

Conceitos-chave:

  • Flex Container:elemento com display: flex
  • Flex Items:elementos filhos dentro do container
Propriedades do Flexbox

Categoria Propriedade Descrição
Definição display Define o container como flex (flex)
Sequência flex-direction Direção dos itens (row, column, etc.)
flex-wrap Quebra de linha (wrap, nowrap)
flex-flow Shorthand para direction + wrap
order Ordem dos itens individualmente
Alinhamento justify-content Distribuição do espaço no eixo principal
align-items Alinhamento no eixo transversal
align-self Alinhamento individual de um item
align-content Alinhamento em containers multi-linha
Expansão flex-basis Tamanho base antes de crescer/encolher
flex-grow Fator de crescimento
flex-shrink Fator de encolhimento
flex Shorthand para basis + grow + shrink

Exemplo prático: O mesmo formulário, agora implementado com Flexbox. Cada par de rótulo+campo é envolvido em uma < div class="form-row" > com display: flex. As propriedades flex: 1 (rótulo) e flex: 2 (campo) definem que o campo tem o dobro da largura do rótulo. justify-content: flex-end alinha os elementos à direita.

3.4.4 Layout Grid

O Grid Layout é o sistema mais moderno e poderoso, permitindo layouts bidimensionais (linhas E colunas simultaneamente), ao contrário do Flexbox que é unidimensional.

Conceitos-chave:

  • Grid Container: elemento com display: grid
  • Grid Items: elementos posicionados dentro da grade
Propriedades principais do Grid

Categoria Propriedade Descrição
Definição display Define o container como grid (grid)
Estrutura grid-template-columns Número e tamanho das colunas
grid-template-rows Número e tamanho das linhas
grid-template-areas Define áreas nomeadas do grid
grid-template Shorthand para áreas, colunas e linhas
grid Shorthand completo
Posicionamento grid-column-start/end Início/fim horizontal do item
grid-row-start/end Início/fim vertical do item
grid-column Shorthand para coluna
grid-row Shorthand para linha
grid-area Shorthand para posição completa
Alinhamento justify-self / justify-items Alinhamento horizontal
align-self / align-items Alinhamento vertical
justify-content / align-content Alinhamento do grid no container
Espaçamento row-gap / column-gap / gap Espaços entre linhas e colunas

Exemplo prático: O formulário implementado com Grid. O < form > é definido como display: grid com grid-template-columns: 1fr 2fr (duas colunas, a segunda com o dobro da largura da primeira). grid-gap: 16px define o espaçamento. Os rótulos usam grid-column: 1/2 e os campos/botão usam grid-column: 2/3. Não são necessários elementos < div > extras, tornando o HTML mais limpo.

3.5 Resumo e Perspectivas

Pontos-Chave

  1. Regras CSS definem como o conteúdo de elementos HTML deve ser exibido
  2. Cada regra tem um seletor (quais elementos) e uma declaração (como exibir)
  3. Declarações consistem em propriedade + valor
  4. Três formas de inclusão: externa (recomendada), interna e inline
  5. CSS pode estilizar textos, listas, tabelas e formulários
  6. Três sistemas de layout:
    • Float: elementos "flutuam" no fluxo de texto
    • Flexbox: layout unidimensional (linha OU coluna), flexível
    • Grid: layout bidimensional (linhas E colunas), o mais flexível
